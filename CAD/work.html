📝 2D編集の操作方法▼
  • 頂点移動: 赤い点を掴んでドラッグ
  • 辺を曲げる: 辺（線）の途中を掴んでドラッグ
  • 点を増やす: 「➕ 点を増やす」をONにして、辺の近くをクリック（Shiftキーを押しながら辺上を選択）
  • 角丸め加工: 「📐 角を丸める」をONにして頂点をクリック（ダブルクリック／右クリック）
⚡ ショートカット▼
  • V : 寸法 ON/OFF
  • T : 半透明切り替え
  • A : 視点リセット
  • X / Y / Z : 指定軸へ接着・ジャンプ
  • Shift + X / Y : 隣のパーツへ接着
  • Shift + Z : 地面にピッタリ接地
  • Alt + X / Y / Z : 指定軸で＋90度回転
  • Ctrl + C : パーツの複製
  • Ctrl + S / O : 保存 / 読込
  • Ctrl + Z / Y : 操作の戻る / 進む
